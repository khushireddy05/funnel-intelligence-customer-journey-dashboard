# Funnel Intelligence & Customer Journey Dashboard

An end-to-end portfolio analytics project that follows synthetic customers from their first marketing interaction through lead generation, sales, customer care, and repeat purchase.

> **Data disclaimer:** all customer, sales, and service data generated by this project is synthetic. Vehicle names are used only as demo categories.

## What this project answers

- Which channels generate high-quality leads and purchases?
- At which acquisition stage are customers dropping off?
- Which products, regions, and customer segments convert best?
- How quickly do customers progress through the sales journey?
- Is customer-care performance associated with satisfaction and repeat purchase?

## Architecture

```text
Synthetic source data
        ↓
Python validation and cleaning
        ↓
Analytical fact and dimension tables (CSV)
        ↓
SQL validation / exploration
        ↓
Power BI model and DAX measures
        ↓
Stakeholder dashboard pages
```

## Quick start

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 -m src.pipeline
MPLBACKEND=Agg python3 -m src.dashboard_artifacts
```

The pipeline writes raw data to `data/raw/`, cleaned data to `data/processed/`, and data-quality outputs to `data/quality/`. The dashboard-artifact command creates an executive preview image and a data-driven insight report.

## Interactive web dashboard

Run the Streamlit dashboard locally after the pipeline has produced the processed tables:

```bash
streamlit run app.py
```

For deployment to a shareable web URL, follow [the Streamlit deployment guide](docs/streamlit_deployment.md).

## Power BI setup

1. Open Power BI Desktop and select **Get data → Text/CSV**.
2. Import all CSV files in `data/processed/`.
3. Create relationships using `docs/data_model.md`.
4. Add the measures in `powerbi/dax_measures.md`.
5. Build the six report pages described in `docs/dashboard_specification.md`.

## Key assumptions

- A customer is counted once per funnel stage using the first time they reach it.
- Acquisition funnel: Interaction → Engaged Prospect → Lead → Qualified Lead → Opportunity → Offer → Purchase.
- Customer care is post-purchase and is not a required acquisition-funnel stage.
- A repeat purchase is a second completed purchase by the same customer in the generated reporting period.
- Marketing attribution uses the customer’s first recorded marketing channel.
